# Friday Room Cleaning

Weekly rota for cleaning the kids' room at the family house. Four groups take turns, one per Friday:

1. Ahmed + Sadiq
2. Mohammed Hussain + Sayed Ali
3. Mohammed Hassan + Sayed Mohd Hadi
4. Haidar Ali + Mohammed Yaqoob

Open the page: it shows who cleans this Friday and the next 8 weeks. No server, no build.

- **Use it:** enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root), then share the link.
- **Change people or restart the rotation:** edit `GROUPS` and `START` at the top of the script in `index.html`.
- **Self-check:** open `index.html?test` and look at the browser console; no assertion errors means it passes.
